# Bassma Housbane Portfolio

Welcome to my personal portfolio! This project showcases my skills, projects, and experience as a full-stack web developer.

## About Me

Hi! I’m Bassma Housbane, a passionate software developer who loves creating clean, functional, and visually appealing web applications. I specialize in ReactJS, Laravel, and MySQL, and enjoy designing smooth user experiences.

## Portfolio Sections

- **Home:** Introduction and personal tagline.

- **About:** My background, education, and experience.

- **Skills:** Technologies, tools, and frameworks I master.

- **Projects:** My personal and professional projects with detailed descriptions.

- **Contact:** Contact form and links to GitHub, LinkedIn, and other profiles.

## Technologies Used

- **Frontend:** ReactJS, Vite

- **Tools & Libraries:** Git, GitHub, TailwindCSS, React Router

## Features

- Responsive design for mobile, tablet, and desktop.

- Smooth scrolling between sections.

- Interactive buttons and hover effects.

- Semi-transparent navigation bar with glassmorphism effect.

- Mobile-friendly layout with adaptive font sizes.

## Getting Started

1. Clone the repository: git clone https://github.com/b24h/portfolio.git

2. Navigate to the project folder: cd portfolio

3. Install dependencies (if using ReactJS locally): npm install

4. Start the development server: npm run dev

5. Open your browser and visit: http://localhost:5173
